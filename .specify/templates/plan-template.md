## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

Verify against `.specify/memory/constitution.md` (v1.0.1+). All items MUST pass
or be recorded under Complexity Tracking with explicit justification.

- **I. Single-writer**: Book state for a symbol is owned by one goroutine;
  ingress via channel only. No mutex/RWLock/atomic shared book state.
- **II. Deterministic replay**: Matching behavior has (or adds) tests that
  produce byte-identical trade output for a fixed input sequence.
- **III. Benchmarks**: Any throughput/latency claim cites `go test -bench`
  with orders/sec and p50/p99 under realistic load — or makes no claim.
- **IV. Narrow scope**: Feature stays within limit/market/cancel, single
  asset class, in-memory; no persistence, multi-node, or FIX unless the
  constitution was amended to allow it.
- **V. Stdlib first**: Third-party deps listed with one-sentence justification
  each; otherwise stdlib only.
- **VI. Strategy honesty**: If strategy/market-maker work is in scope, docs
  and comments do not claim profitability or production-ready trading.
- **VII. Observability**: Trade matches and book-state changes emit
  structured events on a channel (or the plan schedules that emission).
